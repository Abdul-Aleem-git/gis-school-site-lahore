## What This Project Does

This project uses GIS and spatial analytics to answer two core business questions for a private school investor:

1. **Where** in Lahore should a new private school be located?
2. **How much investment** is required, and how many students are needed to break even?

It combines four open-source datasets, applies Kernel Density Estimation (KDE), a KD-Tree school gap analysis, and Multi-Criteria Decision Analysis (MCDA) to produce a ranked investment map of Lahore with full financial modelling at a PKR 3,000/student/month fee level.

## How to Run the Notebook

### Step 1 — Install Required Libraries

All libraries are standard open-source packages. Install via pip:

```bash
pip install geopandas rasterio osmnx scipy matplotlib pandas shapely
```

Or with conda:

```bash
conda install -c conda-forge geopandas rasterio osmnx scipy matplotlib pandas shapely
```

> **Note:** `osmnx` is best installed via conda-forge to avoid dependency conflicts.

### Step 2 — Place Data Files

Copy the four data files into the `Data/` folder next to the notebook:

| File | Download Source |
|---|---|
| `gadm41_PAK_3.json` | https://gadm.org → Pakistan → Level 3 |
| `lahore_schools.geojson` | Overpass Turbo: `amenity=school` within Lahore boundary |
| `Schools.csv` | Punjab PITB open data portal |
| `pak_pop_2024_CN_100m_R2025A_v1.tif` | https://hub.worldpop.org → Pakistan 2024 100m |

### Step 3 — Run

Open Jupyter and select **Kernel → Restart & Run All**.

```bash
jupyter notebook MSDS25022_GIS_School_Site_Selection.ipynb
```

**No path changes needed.** All paths use `os.getcwd()` and are fully relative.

> ⚠️ Section 4 (OSMnx road download) and Section 8 (KDE evaluation on 500×500 grid) may each take 1–2 minutes on first run. Outputs are saved automatically.

## Analysis Pipeline

```
WorldPop Raster (100m) → Gaussian smooth (σ=3) → Population Demand Surface ──┐
                                                                                ↓
OSM Schools + PITB (1,937 pts) → KDE (bw=0.10) → Competition Surface          │
                               → KD-Tree gap  → School Gap Surface   ──────→ MCDA Score → Ranked Sites
                                                                                ↑
Zameen.com / Graana (12 areas) → griddata('nearest') → Cost Surface ──────────┤
                                                                                ↑
OSMnx Road Network (376k edges) → Edge density → Accessibility Surface ───────┘
```

### MCDA Weights

| Criterion | Weight | Method |
|---|---|---|
| Child Population Density | 35% | WorldPop KDE (Gaussian filter σ=3) |
| School Gap | 30% | KD-Tree nearest-school distance |
| Low Property Cost | 20% | Zameen.com spatial interpolation (nearest) |
| Road Accessibility | 15% | OSMnx edge density + Gaussian smooth |

### Financial Model

- **Fee assumed:** PKR 3,000 per student per month
- **Fixed monthly costs:** Staff PKR 250,000 + Utilities PKR 35,000 + Admin PKR 25,000 + Setup amortization PKR 50,000
- **Break-even:** Total monthly cost ÷ fee per student
- **Profit scenarios:** Modelled at 100, 150, and 200 enrolled students

## Key Technical Decisions Explained

**Why KD-Tree for school gap instead of KDE inverse?**  
KDE inverse produces near-zero values almost everywhere because KDE probability densities are tiny numbers. KD-Tree nearest-school distance gives an intuitive and spatially complete metric: every pixel gets a real distance in metres to the nearest school.

**Why `griddata(method='nearest')` for property costs?**  
Linear interpolation only works within the convex hull of sample points — leaving parts of Lahore uncovered. Nearest-neighbour assigns every pixel to its closest area centroid, covering 100% of the city.

**Why `set_bad(alpha=0)` on colourmaps?**  
Pixels outside the Lahore boundary are set to `NaN`. Matplotlib's `imshow` renders NaN values using the colourmap's "bad" colour — by setting this to fully transparent (`alpha=0`), no colour bleeds outside the boundary.

**Why `origin="lower"` everywhere?**  
Our grid is built south-to-north (`np.linspace(MINY, MAXY)`), matching Cartesian convention. All `imshow` calls use `origin="lower"` consistently. The WorldPop raster (which is north-up / row 0 = north) is flipped once with `np.flipud()` in Section 5 to align.
